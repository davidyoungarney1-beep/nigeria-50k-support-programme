# Nigeria ₦50,000 Support Programme

A responsive, static public-information website.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment to finish.

## Important publishing safeguards
This repository is an independently published information page. It does not claim to be operated by, endorsed by, or affiliated with the Federal Government of Nigeria or the Central Bank of Nigeria. Do not add official logos, claims of approval, application forms, personal-data collection, payment instructions, or beneficiary promises unless the programme administrator has verified authority and supplied approved content. Update the notice and administrator details only after legal/communications approval.
